# site/

The documentation site, built with Astro and Starlight and deployed to GitHub
Pages at https://madeintandem.github.io/tiller/ by `.github/workflows/docs.yml`.

What to know before you touch it:

- `src/content/docs/spec/`, `contributing.md`, `releasing.md`, and `cli.md`
  are generated by `scripts/sync-docs.mjs` from the repo's own markdown
  (`docs/spec/`, `CONTRIBUTING.md`, `docs/releasing.md`,
  `docs/tiller-commands.md`) and are gitignored. Edit the source in the repo,
  never the copy; `npm run dev` and `npm run build` regenerate them.
- `index.mdx`, `quickstart.md`, `concepts.md`, `skills.md`, and `console.md`
  are authored here.
- The look is the console's visual system, mapped onto Starlight's variables
  in `src/styles/tiller.css` from `ui/src/styles/tokens.css`: paper, panel,
  and recess surfaces, the ink ramp, the heading navy, one magenta accent
  reserved for the call to action and the current page, Space Grotesk for
  headings, Inter for text, Space Mono for code. The fonts in `src/fonts/` are
  the same files the console embeds. Keep both themes in step.
- Write plainly, no em dashes, the same as the rest of the repo (root
  `AGENTS.md`).

Commands: `npm ci`, `npm run dev`, `npm run build` (output in `dist/`,
gitignored), `npm run preview`. `npm run build` first fetches the Pagefind corresponding-source archive with the GitHub CLI (`gh`, authenticated) unless the verified archive is already in `public/`; `npm run dev` does not need it.

The console screenshots in `public/` (`console-home-*`, `console-map-*`,
`console-fix-*`) are shot from an Acme stand-in project that
`screenshots/acme.sh` builds through the tiller CLI, by `screenshots/shoot.mjs`
in WebKit; `screenshots/README.md` has the reshoot steps. Reshoot them when
the console changes shape, never edit a project's `.tiller/` by hand to pose
a shot: add the state to the script.
